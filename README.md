# fake-news-detection-system
An AI-powered web application that analyzes news headlines and articles to determine whether they are REAL or FAKE using advanced language models. The project provides real-time credibility analysis with confidence scores, reliability metrics, and key misinformation indicators.

Features
🔍 Detects fake or real news articles instantly
📊 Displays confidence percentage and reliability analysis
🧠 AI-generated explanation for each prediction
⚡ Interactive futuristic UI with responsive design
📈 Reliability breakdown:
Source credibility
Factual accuracy
Language objectivity
Logical consistency
🚨 Highlights misinformation indicators
🔑 Secure API key input (stored only in browser session)
Technologies Used
HTML5
CSS3
JavaScript
Anthropic Claude API
How It Works
Enter your Anthropic API key.
Paste a news headline or article.
Click Detect Fake News.
The AI analyzes the content and returns:
Verdict (REAL / FAKE)
Confidence level
Summary explanation
Reliability metrics
Key indicators
